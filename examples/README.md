# AI Detection Results

This directory contains real example outputs generated by the CropAI disease detection system.

The examples demonstrate crop identification and crop-specific disease classification using the trained AI models.

## Example Results

| Crop | Detected Condition |
|---|---|
| Corn | Common Rust |
| Cotton | Leaf Curl Virus |
| Paddy | Bacterial Panicle Blight |
| Sugarcane | Red Rot |
| Wheat | Septoria |

The results demonstrate the inference pipeline from leaf image input to disease prediction and confidence-based analysis.

Prediction performance can vary depending on image quality, lighting, leaf orientation, disease severity, background conditions and similarity to the training dataset.

These examples are provided to demonstrate the prototype and should not be considered a substitute for professional agricultural diagnosis.
