Hand-Drawn Schematics

The schematics/ directory contains the hand-drawn circuit schematics and hardware connection diagrams developed during the design and prototyping of this project.

These schematics document the physical implementation of the system, including:

Arduino UNO Q connections
Camera and sensor connections
Power supply and battery connections
Other hardware interfacing used in the prototype

The hand-drawn schematics are included to provide a clear reference for the hardware architecture and wiring used during development.

Arduino Connections	Microcontroller pin and peripheral connections
Sensor Connections	Connections between sensors and the controller
